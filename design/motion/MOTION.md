# 潮息 · Tidal Breath

**外设电量面板 · 动效语言 v1**
2026-10 · 方案稿，未应用到 `ui/`

---

## 0. 一句话

> 让这块玻璃有生命体征：**呼吸来自电量本身，变化发生时先承接、再宣告，之后安静下来。**

现状并不缺材质。玻璃、镜面边、噪点、指针柔光都做得足够好；缺的是**时间维度**——界面有很好的皮肤，却没有脉搏。这套语言只做一件事：给「状态变化」一套可复用的运动语法，同时不碰现有的视觉身份。

---

## 1. 诊断：呼吸感为什么消失

对照 `ui/styles.css` 与 `ui/app.js` 的现状盘点，问题不在「动画太少」，而在**运动只服务于材质，不服务于状态**：

| 现象 | 证据 | 观感 |
|---|---|---|
| 动效只在指针下发生 | `.row:hover` 上浮 1px、`.ctrl` 悬停发光（styles.css:787-803, 313-326） | 指针一离开，界面死寂 |
| 一次性入场撑起全部叙事 | `.panel` 的 `panel-in` .62s + 5 行 `rise` 级联（styles.css:1293-1318） | 打开那 1.15s 有戏，之后没有 |
| 状态切换普遍硬切 | 低电泛红瞬变（:1036）、alert-tag 瞬现、离线行 opacity 瞬变、banner 靠 `hidden` | 变化「发生」了，但没有「被看见」 |
| 内容交接不完整 | 换主卡只有卡片回弹 320ms + 数字滚动；名称/图标/传输/副标题直接覆写（app.js:628-667） | 像换台，不像交接 |
| 列表没有生命周期 | `appendChild` / `remove()` / `insertBefore`（app.js:557-589） | 行凭空出现、凭空消失 |
| 循环周期互相打架 | 7s / 5.6s / 3.4s 不可整除（styles.css:1255-1268） | 视觉拍频，越看越不安 |

一句话：**glassy / quiet / precise——玻璃、安静、精确，唯独没有「承接」。**

---

## 2. 世界：潮汐池，不是仪表盘

面板本身已经是一块「液态玻璃」。我们不另起一个视觉宇宙，只给它一个时间隐喻：

- **玻璃是容器，电量是水位。** 液面在环的末端——环填到哪里，哪里就是水面；水面有一小段更亮的弧（meniscus），随电量转到同一角度。
- **呼吸来自电量，不是装饰。** 电量充足时呼吸慢而深（7.2s），充电时换成电流的节律（5.4s 并叠加一段巡游弧），低电时变浅变快（3.6s），离线时**停止呼吸**（不是变红）。
- **一次操作是一次「让位」。** 你点过东西之后的 900ms，外晕主动降低振幅，把注意力还给内容；之后潮汐自己回来。
- **变化先发生，再被看见。** 环追值 720ms、数字滚动 620ms、内容交叉 320ms——没有一个变化是「瞬间替换」。

命名取「潮息」：潮是尺度的比喻（慢、周期、可预期），息是呼吸（生命体征），也对应所有周期共用 1.8s 基准脉冲这件事。

---

## 3. 三条原则

1. **一条主线。** 所有常驻运动都由同一个 1.8s 基准脉冲派生；相位从主环（0s）向外晕（+0.7s）传播，光像从心脏推出去，而不是三处各跳各的。
2. **先承接，再宣告。** 状态变化的第一步永远是「旧内容让位 / 容器先变」，第二步才是「新内容就位」。禁止在同一帧替换文字并切换颜色。
3. **进出不对称。** 进入用 `--ease-out`（快到达），离开用 `--ease-in`（快速收束）；退场时长普遍是进场的 0.6–0.75×。离开不该比到来更隆重。

---

## 4. 时间标尺：八级，按「呼吸一次」封顶

所有时长都在 `:root` 里，乘以全局倍率 `--td-speed`（演示页的 0.25× 慢放就靠它，层次比例不变）。

| 令牌 | 值 | 用途 | 直觉 |
|---|---|---|---|
| `--m-0` | 0ms | 焦点环 | 不等：键盘用户的第一反馈 |
| `--m-1` | 80ms | 按下 | 压实，不是弹起 |
| `--m-2` | 120ms | 悬停进入 | 指针一碰就到 |
| `--m-3` | 180ms | 悬停离开 / 回弹 | 收回比进入慢一点 |
| `--m-4` | 240ms | 状态色 / 标签 / 在线点 | 「换了」但不打断阅读 |
| `--m-5` | 320ms | 内容承接 / 数字滚动 / 抽屉 | 一段话被换掉的时间 |
| `--m-6` | 440ms | 抽屉 / banner / 列表重排 | 布局移动，眼睛跟得上 |
| `--m-7` | 600ms | 面板入场 / 主卡交接主段 | 一次呼吸的十分之一 |
| `--m-8` | 720ms | 环追值 / 交接收束 | 数据追上来 |

**为什么是八级而不是更多**：0–180ms 是「反馈」，240–440ms 是「状态」，600–720ms 是「叙事」。超过三档，实现时就会随手取一个「差不多」的值，语言随之瓦解。

### 呼吸时钟：一条 1.8s 的基准脉冲

```
基准脉冲 1.8s
空态等待  10.8s  ×6   ██████████████████████████████████████████████████████████████████
呼吸       7.2s  ×4   ████████████████████████████████████████
充电       5.4s  ×3   ██████████████████████████████
低电       3.6s  ×2   ████████████████████
```

四条周期全部是 1.8s 的整数倍，叠在一起不会互相追赶。相位偏移：主环 0s → 主卡 +350ms → 外晕 +700ms。

呼吸波形：**吸气 34% → 屏息到 44% → 呼气 56%**（`td-breathe`）。呼气比吸气长，才有「松」的感觉；对称的正弦只是呼吸机。

## 5. 缓动：五条，各司其职

| 令牌 | 曲线 | 用在哪 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 一切「出现 / 到达」 |
| `--ease-in` | `cubic-bezier(.5,0,.9,.4)` | 一切「消失 / 离场」 |
| `--ease-in-out` | `cubic-bezier(.65,0,.35,1)` | 两端都慢的空间位移（心跳、抽屉） |
| `--ease-breath` | `cubic-bezier(.45,0,.55,1)` | 呼吸、tint 泛色等长过渡 |
| `--ease-press` | `cubic-bezier(.3,0,.3,1)` | 按下：几乎线性，只压实 |

**反对**所有 `ease` 默认值、`ease-out-cubic` 之外的随手曲线。现状里 `.caret` 用的就是浏览器默认 `ease`（styles.css:906），这是语言漏出去的第一个口子。

## 6. 空间预算：1–10px，拒绝大位移

玻璃是重的。运动幅度必须像被手指按住，而不是弹起来。

| 场景 | 值 |
|---|---|
| 行悬停抬升 | `-1px` |
| 主卡悬停抬升 | `-2px`，缩放 `1.012` |
| 按下 | 行 `0.988`，图标按钮 `0.94` |
| 入场位移 | `8px`（行 / 内容） |
| 退场位移 | `6px` |
| 主卡交接 | 旧内容上移 `4px`，新内容自下 `6px` |
| 面板从托盘出现 | `10px` + `scale(.98)` |
| 列表错峰 | `40ms`，最多 4 级（总延迟 ≤160ms） |

任何超过 10px 的位移、任何超过 1.03 的缩放，在这套语言里都需要单独论证。

## 7. 三层结构：谁在动，动多少

| 层 | 成员 | 节律 | 目的 |
|---|---|---|---|
| **环境层** | 外晕 `.stage::before`、主环 glow、环上潮痕、在线点 | 常驻，7.2s 家族，振幅 ≤0.36 | 证明「活的」，不索取注意 |
| **反馈层** | hover / press / 数值更新 / 充电 / 低电 / toast / banner | 事件驱动，80–720ms | 让每一次变化都被看见 |
| **叙事层** | 面板入场、主卡交接、列表增删、抽屉 | 每次发生一次，600ms 级 | 解释层级与因果，随后退场 |

**预算**：常驻循环 3 层（外晕 / 主环 / 在线点），每帧 JS 0（复用现有 specular / spotlight rAF），新增依赖 0。

## 8. 主环：把电量读成生命体征

主环是这套语言的主角。呼吸跑在**内层 `.glow`** 上，节律切换跑在**外层 `<g>`** 的 opacity 交叉淡换上——两层同时存在，只交叉透明度，**永远不修改正在运行的 `animation-duration`**（那会让相位跳变，正是现状充电时「突跳」的原因）。

```
<g class="breath-normal"><circle class="glow"/></g>   7.2s
<g class="breath-charge"><circle class="glow"/></g>   5.4s
<circle class="fill"/>      环值 720ms 追值
<circle class="shine"/>     每个周期扫过一次的「潮痕」
<circle class="current"/>   充电时巡游的电流弧
<circle class="meniscus"/>  液面：环末端随电量旋转的亮弧
```

| 状态 | 呼吸 | 潮痕 | 液面 | 其它 |
|---|---|---|---|---|
| 常态 normal | 7.2s，.06→.24 | 有 | 显示 | — |
| 充电 charging | 5.4s，.10→.36（交叉 600ms 浮现） | 有 | 显示 | 电流弧 360° 巡游，5.4s/圈 |
| 低电 low | 3.6s，.08→.22 | 有 | 显示 | 心跳 `td-beat` 1.8s ×3 后收；面板 tint 600ms 泛红 |
| 预警 amber | 同常态 | 有 | 显示 | 仅换色 240ms |
| 离线 offline | **停**（`animation:none`，opacity .06） | 无 | 隐藏 | 在线点转灰、停止脉冲 |
| 未知 unknown | 停 | 无 | 隐藏 | 空心环 + 「未知」，**不得判红** |
| 空态 empty | 10.8s，.04→.10 | 无 | 隐藏 | 扫描弧 10.8s 绕一圈 |

注意：离线规则必须同时命中内层 `.glow`，否则「静帧」仍在偷偷耗帧——这是实现时最容易漏的一处。

## 9. 事件语汇：12 个场景

每个场景都是「状态 → 运动」，不是「元素 → 属性」。

| # | 场景 | 机制 | 时长 |
|---|---|---|---|
| 1 | **常态呼吸** | 外晕 / 主环 / 潮痕 / 在线点同一网格，相位外错 | 7.2s |
| 2 | **静息让位** | 操作后外晕振幅降到 .16–.40，900ms 后回 | 900ms |
| 3 | **离线停息** | 环色转灰 240ms；呼吸两层归零；在线点停脉冲 | 240ms |
| 4 | **悬停与按下** | 进 120ms、按 80ms、离 180ms；位移 1–2px | 80–180ms |
| 5 | **电量更新** | 环 720ms 追值 + 液面转向 + 数字 620ms + 行内数值 320ms | 720ms |
| 6 | **充电接入** | 双层呼吸交叉 600ms + 环色 240ms + 电流弧浮现 | 600ms |
| 7 | **低电心跳** | tint 600ms 泛红 + 心跳 ×3（1.8s）+ 呼吸降频 + 提示条 | 5.4s |
| 8 | **提示与横幅** | banner 用 `grid-template-rows: 0fr→1fr` 推开列表 440ms；toast 进 260 / 退 180 | 440ms |
| 9 | **主卡交接** | 旧内容上移淡出 160ms → 新内容升起 320ms + 数字 620ms + 环 720ms | 620ms |
| 10 | **设备增减** | 行退场 180ms（淡出右移、不塌高度）→ 其余行 FLIP 440ms → 新行升起 320ms 错峰 40ms | 440ms |
| 11 | **设置抽屉** | 遮罩 240ms 先暗，抽屉 320ms 滑入；关闭反向、`visibility` 延迟等滑出结束 | 440ms |
| 12 | **首次入场** | 面板 600ms 浮起（唯一允许的一次性 blur）→ 内容 40ms 错峰 | 600ms |

### 关键修补（对应现状 §6 的缺口）

- **主卡交接**不再只回弹卡片：名称、图标、传输标签、副标题、警示标签一起走「让位 → 就位」。
- **日常数值变化**也有承接：环在追值，数字在滚，行内数字 320ms 跟到位——但只有 720ms，不打断阅读。
- **列表增删**有完整生命周期：先退场再 FLIP，高度不塌陷、不瞬跳。
- **toast 有退场**：`.is-leaving` 180ms 后才删除节点；仍是 4.2s 自动消失。
- **抽屉遮罩**先暗后进，层级被交代清楚。
- **低电不是永久警报**：心跳只跳三次，之后回到 3.6s 的浅呼吸；解除低电时用一次 `td-release` 舒展收尾。

## 10. 降低动效：衰减，不是关闭

现状把 `animation / transition` 压到 `0.001ms`（styles.css:1335-1351），等于把变化本身也关掉了——用户看不到「东西变了」。

潮息的做法：

- 循环层**停**：外晕、潮痕、电流弧、心跳、扫描弧全部 `animation:none`，改成静帧（外晕 opacity .42，环 glow .12）。
- 变化层**留**：所有 transition 统一降到 **120ms**，且只允许 `opacity / color / background-color / border-color` 四个属性（不再有位移与缩放）。
- 入场保留，但去掉 `filter: blur()`。
- 系统 `prefers-reduced-motion` 与设置项 `data-reduced-motion="true"` 走同一套规则（两段选择器，内容一致）。
- 原来「关闭柔光与涟漪」的文案相应改为「降低动效（保留状态变化）」——涟漪与指针柔光仍可关，但状态变化不能被关掉。
- **分阶段落地**：v0.2.0 仍沿用现网 `0.01ms` 全关（与 preview 一致、零回归）；本节这 120ms 衰减是 **v0.3 目标**，切换前按 §16.4 验证。

**对比度**：所有新增层只加光、不压暗文字；`--t2` 正文 .86 白在烟熏底上仍 ≥4.5:1。呼吸最低点也不会把信息压到不可读（环值、数字是实色，不参与呼吸）。

**键盘**：焦点环 0ms（`--m-0`），Enter/Space 选主卡与指针点击走同一套涟漪 + 交接，不再只有鼠标有反馈。

## 11. 性能契约（沿用现有硬约束）

| 项 | 潮息 |
|---|---|
| `backdrop-filter` | 生产 0 个（保持） |
| `mix-blend-mode` | 0 个（保持） |
| `box-shadow` 进 transition | 禁止（保持；hover 仍是预烘焙伪元素只动 opacity） |
| 动画属性白名单 | `transform / opacity / stroke-dashoffset / color / background-color / border-color`；唯一例外：入场一次性 `filter: blur()` |
| 常驻循环层 | 3 层（外晕 / 主环 / 在线点） |
| 每帧 JS | 0（复用现有 specular / spotlight rAF，新增动画全在 CSS） |
| 新增依赖 | 0 |
| 隐藏态四契约 | 不变：pause 全部动画、停 rAF、清 timer、不写 DOM |
| 协议 | 0 改动 |

隐藏态的额外收益：离线/未知时呼吸真正停掉（`animation: none`），不再有无意义的合成工作。

**可观测的验收**：`getAnimations().length` 在静息态约为 6–7 个（外晕、主环双层、潮痕、在线点、行内充电呼吸；充电层不运行时 `paused`，不占合成）；隐藏后应为 0 且 rAF 停。演示页右上角「全部暂停」就是同一套机制的手动验证。

## 12. 落地方式（本次不做）

这一版是**可启用层**，不是改版：

```html
<!-- 将来启用时：ui/index.html -->
<html data-motion="tidal">
  <link rel="stylesheet" href="styles.css">
  <link rel="stylesheet" href="../design/motion/tokens.css">  <!-- 放在后面 -->
```

- 所有规则都挂在 `html[data-motion="tidal"]` 下；删掉该属性即回到 v0.1.2 的现行动效，可灰度、可回滚。
- 令牌前缀 `--m-*` / `--td-*`，不与现有 `--ease` / 颜色 token 冲突。

### 需要配合的三处结构改动

1. **主环分层**：`buildRing()` 内把单个 `.glow` 换成 `<g class="breath-normal">` + `<g class="breath-charge">` 两层，并补 `.shine / .slide / .current / .meniscus` 四个 circle（或按需只上 meniscus + 双层 glow）。
2. **banner 内层**：`#banner` 内包一层 `.banner-inner`，才能用 `grid-template-rows: 0fr→1fr` 做高度过渡。
3. **抽屉遮罩**：`.drawer-scrim` 从 `hidden` 属性改为 `.is-shown` 类 + `aria-hidden`，否则透明度过渡无处附着。

### 需要配合的 JS 改动点（5 处）

| 位置 | 改动 |
|---|---|
| `renderHero`（app.js:601-675） | 环追值/液面角度写入；内容交接走「让位 160ms → 就位 320ms」；数字滚动保留 620ms |
| `renderList` / 行增删（app.js:557-589） | 增删前后记录 `getBoundingClientRect` 做 FLIP；行退场动画结束后再删节点 |
| 状态切换（`setRingState` / `applyHero`） | 颜色与呼吸层交叉交给 CSS；JS 只切状态类，不再直接写 `style` |
| toast（app.js:1188-1210） | 删除前加 `.is-leaving`，180ms 后再 `remove()` |
| 降低动效（app.js:1499-1511） | 改为设置 `data-reduced-motion`，由 CSS 统一衰减；同步更新设置项文案 |

## 13. 验收清单

- [ ] 静息态常驻动画 ≤7 个，且都在同一张 1.8s 网格上；非充电时充电层 `paused`
- [ ] 指针离开后，界面仍有可感知但不打扰的呼吸
- [ ] 连续切换主卡 5 次，无文字瞬换、无数字跳变、无环值倒流
- [ ] 列表增删不塌高度，其余行有 FLIP 位移
- [ ] 低电心跳只跳 3 次后收；解除低电有一次舒展
- [ ] 离线时呼吸完全停止（`getAnimations()` 不含 glows）
- [ ] 降低动效下：变化仍可见（120ms 透明度），循环全部停止
- [ ] 隐藏（失焦）后：动画暂停、rAF 停、timer 清空、DOM 零写入
- [ ] 生产构建 `filter` 计数仍为 0；无新增依赖
- [ ] 250Hz 屏 p99 ≤ 20ms，隐藏态 CPU < 0.5%

## 14. 已知取舍

- **toast 仍会短暂盖住底栏提示**：`.toasts` 固定在 `right:132px / bottom:14px`（styles.css:1042-1053），这是现有布局，本次不动。真要解决是布局问题，不是动效问题。
- **低电阈值仍有两份**：UI 15%（app.js:43）与采集器 20%（collector/settings.py:93），F-04 待统一；动效只消费状态，不参与判定。
- **`RING_C` 仍双份**：CSS `--ring-c`（styles.css:50）与 JS `RING_C`（app.js:34）。落地时建议 JS 读 CSS 变量，避免环值在两边漂移。
- **四个未使用令牌**（`--line / --line-soft / --glass / --glass-hi`）本方案未消费；保留原样，留给后续 `extract`。
- 本方案**没有应用**到 `ui/`，`ui/` 一行未改。

## 16. 与 v0.2.0 功能计划的接口（2026-10-20 整合）

本节由 v0.2.0 计划书（`FEATURE_PLAN.md` §21/§22）评审后追加，规定「潮息」与功能版本的关系。

**一句话：动效语言仍是提案。v0.2.0 不整体启用 `tokens.css`，只落 6 条功能层过渡；本文件的八级标尺、呼吸时钟与场景语汇整体保留到 v0.3。**

### 16.1 四层权威边界

| 层 | 文件 | 回答什么 | 权威性 |
|---|---|---|---|
| 功能与版本 | `FEATURE_PLAN.md` | 做什么、何时做、怎么验收 | 唯一事实源 |
| 动效语言 | 本文 + `tokens.css` | 怎么动、为什么这样动 | 动效规范唯一事实源；v0.2.0 不整体启用 |
| 真机实验室 | `motion-lab.html` + `lab.css` / `lab.js` | 在 720×380 真实面板上验证运动 | **视觉权威**（复用 `ui/styles.css`） |
| 功能交互原型 | `motion-preview.html` + GIF/WebP | 三项功能的交互流程与时序 | 只对交互负责；视觉是简化 mock |

### 16.2 v0.2.0 只启用最小集

| 元素 | 参数 | 说明 |
|---|---|---|
| 设置抽屉 | 260ms `cubic-bezier(.22,.61,.36,1)` + 200ms opacity | 现网已有，沿用 |
| 抽屉遮罩 | 200ms `opacity` | 新增 |
| 开关 | 160ms `cubic-bezier(.2,.8,.2,1)` | 新增 |
| 不透明度滑块 | 无过渡；thumb 按下 140ms `scale(1.15)` | 新增 |
| 面板内 toast | 280ms `--ease` | 现网已有 |
| 系统通知（mock） | 280ms 入 / 240ms 出 | mock，真机由系统接管 |
| 低电高亮 | 250ms `border-color` + 预烘焙层 `opacity` | 新增；不写 box-shadow 过渡 |

这些过渡写在组件 CSS 里，**不使用 `--m-*`、不加 keyframes、不引入 1.8s 时钟**。（表中「系统通知」为演示 mock，不计入 6 条实现量；真机由 Windows 通知中心接管。）

### 16.3 v0.3 收编映射

| v0.2.0 实测 | 潮息令牌 | 差异 |
|---|---|---|
| 260ms 抽屉 | `--m-4` 240ms | −20ms |
| 200ms 遮罩 | `--m-3` 180ms | −20ms |
| 160ms 开关 | `--m-3` 180ms | +20ms |
| 140ms thumb | `--m-2` 120ms | −20ms |
| 280ms toast | `--m-5` 320ms | +40ms |
| 250ms 低电高亮 | `--m-4` 240ms | −10ms |

规则：一次只收编一类交互；先 motion-lab + 真机录屏对照；±40ms 的差异写进提交说明，禁止静默替换。

### 16.4 降低动效分两阶段

- **v0.2.0**：沿用现网 `0.01ms` 全关，抽屉/通知直接出现。满足无障碍底线，且与 preview 行为一致、零回归。
- **v0.3**：采用 §10 的 120ms opacity 衰减 + 环境静帧；切换前在真机与 Windows“关闭动画效果”两种环境各验一次。

### 16.5 生产禁令（v0.2.0 内即生效）

- `box-shadow` 不进 transition：低电高亮用「预烘焙高光层 opacity + `border-color`」；本文件 §8 的 `.low-tint` 是 v0.3 形态。
- `ui/` 保持 0 个 `backdrop-filter`；演示页里的 blur 都是 mock。
- 隐藏态四契约不变：pause 全部动画、停 rAF、清 timer、不写 DOM；新增过渡必须可被 `getAnimations().pause()` 暂停。
- 属性白名单不变：`transform / opacity / color / background-color / border-color / stroke-dashoffset`。

### 16.6 与两个演示页的关系

- `motion-lab.html`：视觉权威，直接复用 `ui/styles.css`；12 场景与时间轴解剖台用于验证语汇，不用于验收功能。
- `motion-preview.html`：交互原型，独立简化视觉（浅色壁纸、简化面板、`backdrop-filter` mock），**不参与视觉验收**；其 `--pa1/2/3` 只是 mock 命名，生产按计划用 `--panel-a1/2/3`。
- 样片参数以实测为准：`reel-*.gif` 560×309、8.3fps；`motion-preview.gif` 780×520、54 帧、首帧 730ms + 其余 60ms ≈ 9.96s、约 6.0MB；`.webp` 约 0.28MB。
