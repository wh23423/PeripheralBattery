规则与预算

这套语言能落地，靠的不是动画多，而是约束硬。

  1. 一条主线。任意时刻只有一个元素在「主呼吸」——主环。其他周期都是它的分频，不允许第二种波形同时争注意力。
  2. 进出不对称。出现用 --ease-out、消失用 --ease-in；进 600ms 的，退 180ms。退场永远比入场快，界面才不拖泥带水。
  3. 先承接，再宣告。状态变化时先给容器一个过渡（tint、外晕、行底色），再换内容。禁止内容瞬间替换而容器不动。
  4. 位移不超过 10px。抬升 1–2px、入场 8px、面板 10px。玻璃是重的，飘不起来的位移一律不用。
  5. 循环必须可收口。所有无限动画都能被 getAnimations().pause() 暂停；隐藏态暂停动画、停 rAF、清 timer、不写 DOM——沿用 v0.1.2 的四条契约。
  6. 降低动效是衰减，不是删除。120ms 的 opacity 过渡保留「变了什么」，去掉「怎么飞过来」；环境层停在静帧，不归零。

落地路径

这不是改版，是一层可启用的覆盖。开关是 html[data-motion="tidal"]，删掉就回到 v0.1.2。

  1. 文件
    design/motion/tokens.css 放在 ui/styles.css 之后引入；index.html 根节点加一个属性。
  2. 结构
    主环 SVG 加三圈：.shine 潮痕、.slide 扫描、.meniscus 液面；呼吸拆成 .breath-normal / .breath-charge 双层；面板内加一层 .low-tint。
  3. 脚本
    主卡交接改成「旧内容下沉 + 新内容升起」；行增删用 FLIP；toast 增加 .is-leaving 退场；抽屉遮罩改 class 过渡；交互后加 body.is-attending 900ms。
  4. 降级
    重写 prefers-reduced-motion 段：120ms opacity 过渡 + 环境静帧，不再把动画压成 0.001ms。

先不应用。本方案交付五个文件：tokens.css（可启用层）、MOTION.md（规格）、motion-lab.html + lab.css + lab.js（本页）。ui/ 没有任何改动。
